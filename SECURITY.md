# Security

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or discussions.

Write to prisma-memory@scientetiq.com with the subject line "Security". Include:

- the version or commit of Prisma Memory;
- what you found and how to reproduce it;
- what an attacker could do with it, as far as you can tell;
- how we can reach you.

Do not include real personal data, passwords or confidential documents in the report.

We will confirm that we have received your report, tell you whether we can reproduce the issue and let you know when a fix is released. Please give us reasonable time to fix the issue before you publish details.

## Scope

This policy covers the Prisma Memory code published in this repository. It does not cover your own installation, your modifications or third-party components, which are maintained by their own authors.
